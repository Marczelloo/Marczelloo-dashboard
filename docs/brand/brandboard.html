05 / GUARDRAILS

Keep it consistent

Te zasady wynikają z obecnego kodu i chronią system przed przypadkowym mieszaniem stylów. Pełna specyfikacja znajduje się w DESIGN.md.

Do

  • Use existing CSS tokens and UI primitives.
  • Render Lucide at 16 px with a 2 px stroke.
  • Combine status color with icon and text.
  • Keep spacing on the 4 px rhythm.

Don’t

  • Introduce another brand accent.
  • Mix icon libraries on one surface.
  • Use emoji as interface icons.
  • Replace tonal depth with heavy shadows.
